# Полный аудит route-страниц и вложенных состояний #59

Инвентарь: все **16** файлов `app/pages/**/*.vue`. Проверка `state audit includes
every route file` сравнивает список с файловой системой: добавленная страница
потребует явно дополнить матрицу. Существующий PR #60 дополнен после уточнения
об обязательном аудите каждой страницы.

## Условия и обозначения

Браузер: production build, изолированный fake API. Каждый применимый сценарий
нового `admin-state-audit.spec.ts` выполняется при **1399×900 и 390×900,
light и dark**. Нет запросов к рабочим стендам. Screenshot каждого состояния
сохраняется в Playwright report/CI artifact; обзорные листы приведены ниже.
Существующие проверки форм дополнительно покрывают 1049 px.

- **E** — успешный ответ без данных: общий inbox и `kind=empty`.
- **F** — пустой результат поиска/фильтра: search и `kind=no-results`, сброс
  внутри actions общего компонента. Отсутствие фильтра отмечено **N/A**.
- **L** — ожидание ответа: loader-circle, `kind=loading`. При первичном
  `await` в async setup действует Vue Suspense: до ответа компонент ещё не
  смонтирован, вместо ошибочного «пока нет» остаётся фон приложения. Это
  существующее поведение маршрутизации, не пустая база. Отдельно удерживается
  повторный запрос в уже открытом компоненте, где есть действие retry.
- **X** — ошибка получения данных: triangle-alert, `kind=error`, role=alert;
  прежние retry/повторное открытие сохранены. Доменные статусы, ошибки формы
  и операций не превращаются в пустую коллекцию.
- **N/A** означает отсутствие такого сценария в интерфейсе/контракте; причина
  указана в каждой строке. Отсутствующие поля не симулируются как пустой ответ
  там, где API возвращает обязательный объект настроек.

Общий компонент задаёт иконку 28×28, min-height 208 px, padding 32×16 px,
gap 12 px, общую типографику/цвета и flex-wrap/центрирование действий.
Панели с собственными заголовками/формами/фильтрами остаются контекстными
контейнерами. Кнопки добавления остаются в заголовках и формах.

## Исходная причина и дополнительно найденные расхождения

Исходная разница: `rag-list` всегда оборачивал **тот же** `ui-empty-state` в
`admin-table-wrap` (фон панели, рамка 1 px, радиус), а факультеты — нет.
Высота/иконка/типографика компонента уже совпадали. Рамка таблицы теперь
применяется при наличии документов; поиск по непустой базе её сохраняет.
Четыре parity-теста упали до исправления именно на рамке и фоне:
[доказательство](regression-before.txt), [до/после](README.md).

Полный аудит дополнительно обнаружил ручные loading/error в rules,
diagnostics, initial connections error, ручные состояния проходных баллов,
пустые вкладки частичной schema и два одновременных loading/error при retry.
Эти data-state поверхности приведены к существующему компоненту без изменения
запросов, прав, условий сохранения, моделей данных и обработчиков операций.

Отдельно сохранены технические/доменные сообщения: неудачный запрос, отсутствие
права, неизвестный статус, отсутствующие metadata и failed indexing не
маскируются под успешную пустую базу.
