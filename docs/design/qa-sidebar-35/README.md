# Прокрутка бокового меню — #35

Production build проверен Playwright с изолированным fake API. Матрица: Chromium / WebKit 27.2 (движок Safari), light / dark, 1049×400 / 390×400; дополнительно высота 1000 px без переполнения.

Проверены большие и малые wheel delta (эмуляция мыши/тачпада), End, обход ссылок клавиатурой и в обратном направлении, видимый фокус и полная видимость «Системных логов», переход по последнему пункту и закрытие мобильного меню. На macOS WebKit используется Option+Tab согласно стандартным настройкам Safari. Физические устройства и Safari.app отдельно не проверялись.

У Chromium отключён стандартный Playwright `--hide-scrollbars`: до исправления системная полоса занимала 15 px, после — 0 px. Нативная прокрутка сохранена через `overflow-y: auto`. Ширина меню стабильна при прокрутке и изменении высоты окна. WebKit на macOS проверен с overlay-полосами; временная настройка Always для тестового приложения не изменила его headless-геометрию.
