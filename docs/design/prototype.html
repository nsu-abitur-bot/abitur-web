Адрес API и дополнительные параметры

Поля и допустимые значения в production берутся из схемы сервера, а не фиксируются в интерфейсе.

Telegram и MAX

Наличие ключа не подтверждает работоспособность канала.

TelegramКлюч задан в примере. Проверки нет.

Редакторы ключей каналов используют тот же безопасный контракт configured и changes. В этом экране показаны только состояния.

Инспектор поиска и автоматическая оценка решают разные задачи.

Показывает найденные фрагменты. Полный ответ бота не генерируется.

Оценка набора вопросов

Запускается отдельно от вопроса слева. В текущем API нет обновляемого прогресса по каждому примеру.

Результат не загружен. Значения точности и времени ответа отсутствуют.

Почему это ещё не ответ бота

Полный ответ проходит через готовые ответы, поиск, генерацию и инструменты. Предпросмотр этого пути требует нового backend-метода. Инспектор показывает только доступный ему этап поиска.

Раздел продукта

Редактор за пределами прототипа

Раздел существует в продукте и должен сохраниться при внедрении новой оболочки. В концепции проработаны материалы, подключения, проверка и сводка.

Недостаточно прав

Материалы и инспектор доступны администраторам. Наблюдатель работает с обращениями и аналитикой. Переключатель роли здесь только демонстрирует доступ, а не меняет авторизацию.

Удалить выбранные материалы?

В текущем API удаление выполняется по каждому документу отдельно. Интерфейс должен сохранять результат каждой операции. Здесь изменяется только пример списка.
