## Решение

Реальные Nuxt-компоненты, не статичная картинка. Размеры 480 / 680 / 800 px по задаче; на телефоне отступ 12 px и центральное открытие. Единые заголовки, поля, разделители и нижняя полоса действий. Прокручивается содержимое, заголовок остаётся видимым. Формы сохраняют обработчики и состояния ожидания/ошибки. Для тем и приглашения действия вынесены в footer.

Логи — последовательные записи с временем и нейтральными разделителями; метаданные раскрываются. Обратная связь — сначала жалоба, вопрос и ответ, служебные данные и JSON свернуты. Диагностика — компактные параметры без декоративных плиток и дублирующих предупреждений.

Панель «Локальное превью» позволяет переключать девять примеров, тему и ошибку сохранения. Она включается только в dev при API http://127.0.0.1:8362 и явном modal-preview=1; это временное средство согласования, до PR его следует убрать из поставки.

## Изоляция
