# Модальные окна · #42

Пользователь одобрил направление локального интерактивного превью: «Стало лучше, пусть доделает ветку».

Это сохранённые материалы согласования на коротких синтетических данных. [Исходное решение](preview-decision.md) описывает именно этап превью; его временные URL и переключатели не входят в поставку.

## Принятый дизайн

- Центральные окна трёх размеров: короткие формы — 480 px, текстовые формы/обратная связь/диагностика — 680 px, логи — 800 px. На мобильном экране сохраняются отступы и центральное открытие.
- Единые заголовки, ритм полей, разделители и полоса действий; содержимое прокручивается отдельно от заголовка. Действия длинных форм остаются доступны при прокрутке.
- Логи представлены последовательными записями с временем; метаданные раскрываются по запросу.
- В обратной связи главные элементы — комментарий, вопрос и ответ; сведения сессии и JSON свёрнуты, действия находятся в footer.
- В диагностике параметры разделены тонкими линиями, без декоративных плиток и дублирования сообщения об ошибке.
- Штатные API, обработчики, проверки ввода и права доступа сохраняются. Панель примеров, синтетические ошибки и привязка к локальному fake API удалены из приложения.
